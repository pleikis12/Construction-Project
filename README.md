UAB Vestar Construction
The official website for UAB Vestar Construction, providing professional construction, preparation, and design services in the Klaipėda region.

🌐 Live Website
https://uabvestar.com

🚀 Tech Stack
- **Framework:** [Vue 3](https://vuejs.org/)
- **Build Tool:** [Vite](https://vite.dev/)
- **Language:** TypeScript
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) 
- **Deployment:** [Vercel](https://vercel.com/)

💻 Local Development
If you need to make changes locally:

1.Install dependencies:

npm install

2.  **Start the development server:**
    ```sh
    npm run dev

3.Build for production:

Bash
npm run build


## 🧪 Testing

*   **Linting:** `npm run lint`
*   **Unit Tests:** `npm run test:unit`
*   **End-to-End Tests:** `npm run test:e2e`

## 📦 Deployment
This repository is connected to Vercel. Every time you `git push` to the `main` branch, the changes are automatically built and deployed to your live website.
